学完不是毕业,是拿到"车手执照"—— 然后一直回来刷圈、搞研究、升段位。
设计哲学

普通培训:上完 16 节课 → 结业 → 学生流失。Crayxus 设计:16 周拿"车手执照"只是入场,之后进入一个像游戏一样永不通关的成长体系 —— 永远有下一个段位、下一个赛季、下一个研究课题、下一个圈速纪录可破。粘性 = 复购(会员/季票)+ 口碑 + 升学作品越攒越厚。

两层结构
第一层 · 车手执照课程(16 周)
按 3×3 框架:① AI 赛道 → ② AI 赛车 → ③ 赛事/AI Tune。每节课都有"动手产出",每 3–4 周一个里程碑,期末班级杯 + 颁车手执照。
▼
第二层 · 永续成长体系(无限)
持执照进入:段位阶梯 + 常驻排行榜 + 赛季制 + 开放实验室 + 研究课题菜单 + 车队传帮带。学生从"上课"变成"做研究 / 刷纪录 / 带队"，越玩越深。

永续成长体系 · 学完之后怎么留住
六个粘性引擎,把"结业学生"变成"长期车手 / 研究者 / 队长"。
六大粘性引擎
① 常驻圈速排行榜
个人最佳(PB)永久记录,随时来刷。班级榜 / 校榜 / 全国榜。像 Strava 一样,看到别人破纪录就想回来再战。
② 赛季制
每赛季(约一学期)换新赛道 + 新规则 + 新挑战,排名部分重置。老车手永远有新目标 → 季票 / 会员复购。
③ 开放实验室(车手俱乐部)
课后 / 周末开放时段,凭段位进入,自由调车、刷圈、做研究。会员制 = 持续收入,也是社群发酵地。
④ 研究课题菜单
学完基础后开放开放式课题(见下表)。学生从"上课"变成"做研究"—— 这正是"继续研究和提高"的载体。
⑤ 车队 + 传帮带
组车队,老车手当助教 / 队长带新人。给身份与归属,跨校战队 PK —— 同时降低你的人力成本。
⑥ 个人数据档案 + 作品集
telemetry 历史 + 作品集持续累积、越来越厚 → 沉没成本留人 + 升学背景提升(写进 IB/EPQ/申请)。

为什么这样设计有粘性 / 有生意: 16 周课程是一次性收入;段位 + 排行榜 + 赛季 + 开放实验室是持续收入(会员 / 季票 / 进阶课题包)。学生有身份(段位)、目标(下一个赛季 / 纪录)、归属(车队)、沉没成本(数据档案)—— 四个都指向"不想走"。这也是把单校客单价从"一学期"拉成"多年"的关键。
