到货验收

每样东西到货当天就验，有问题马上找店家换，别等焊上去才发现。

  1. XIAO ESP32S3 Sense：盒里应有主板、Sense 扩展板（带摄像头、麦克风、TF 卡槽）、2.4G 天线；带摄像头的款还有一片散热片。插 USB-C 线到电脑，设备管理器 / 系统信息里能看到新串口（乐鑫 USB 设备）才算好。
  2. 摄像头型号：不要信丝印和商品标题。烧录项目里的 firmware/tools/cam_id/ 小工具，串口（115200）会打印传感器地址和 ID，对照下面的"摄像头 ID 对照表"确认型号。
  3. ATECC608A 模块：芯片丝印应为 ATECC608A（或 608B，见常见坑）。接到 XIAO 的 3V3 / GND / D4(SDA) / D5(SCL) 后，烧一体机固件，串口应显示"配置区未锁 · 数据区未锁"。验收这一步绝对不要改锁定开关。顺便看模块上有没有 4.7kΩ 上拉电阻（多数有，没有就自己补两颗接 3V3）。
  4. OLED：确认是 SSD1306、128×64、4 针 I2C；对照丝印看针脚顺序（有的是 VCC-GND-SCL-SDA，有的是 GND-VCC-SCL-SDA）。I2C 地址应为 0x3C。
  5. 锂电池：万用表量红黑线之间电压，正常 3.6–4.2V；低于 3.0V 直接退。确认带保护板（电池一端有一小块电路板，包在胶膜里）。量一下尺寸，外壳电池仓按 42×30×10 mm 设计。
  6. 16mm 金属按钮：按下不弹起、再按才弹起 = 自锁款（对）；按下就弹回 = 自复位款（错）。看侧面标签灯电压应为 3–6V。用卡尺量"本体 + 端子"总深度，外壳按 30 mm 设计，差得多就改 enclosure/sitas_cam_case.scad 里的 BTN_DEPTH 重新出 STL。
  7. 快门键：万用表蜂鸣档测两只开关脚按下导通、松开断开；LED 两脚用二极管档能微亮。
  8. MicroSD 卡：容量不超过 32GB，电脑上格式化为 FAT32。
  9. USB-C 线：插电脑能识别出串口才算数据线；只亮灯不出串口的是仅充电线，烧不了固件。
  10. 3D 打印件：先打 plug_gauge.stl 试配目镜筒，再打正式的 plug_plug.stl / plug_dock.stl；外壳盖子应能顺滑盖上、不晃。

常见坑

  • 卖家常把 OV7725 当 OV2640 发。之前买的"XIAO 摄像头"到货就是 OV7725，标题和丝印都不可信。固件报 0x106 not supported 表示"有应答但型号对不上"，先用 cam_id 读 ID 再下结论。
  • 官方 OV2640 已停产。Seeed 官方说明新出货的 Sense 板可能带 OV3660 或 OV5640。通用版固件里已带这两种驱动，但还没有实机验证。先买 1 套到货验证通过，再批量下单。
  • 摄像头排线很脆。原来那颗 OV2640 就是排线触点裂了才坏。插拔时捏住排线根部，别反复对折；装进外壳时给排线留弯曲余量。
  • ATECC608A 锁定是一次性的。配置区一旦锁定永久不可改，锁错 = 芯片报废。所以每批要多备芯片，锁定这一步要两个人一起核对后再做。
  • ATECC608A 和 608B。608A 已逐步被 608B 取代，市面上不少模块其实是 608B。理论上兼容，但本项目只实测过 608A，买 608B 先少量试。
  • OLED 和 ATECC 只能接 3V3。接到 5V 会直接烧坏。两个模块共用同一条 I2C（D4/D5），地址 0x3C 和 0x60 不冲突。
  • 先焊电池线，再叠 Sense 板。XIAO 的电池焊盘（BAT+ / BAT−）在主板背面，叠上扩展板后几乎没法下烙铁。电池最后才接：所有焊点目检无桥连后再接，红黑线剪成不同长度防止碰到一起短路。
  • 天线必须插上。天线座在 USB 口旁边，垂直轻按到"咔哒"一声。不插天线 WiFi 基本连不上；而且板载天线个体差异大，个别板子插了还是弱，换板即好。
  • 锂电过放就废。之前有一块 1200mAh 电池被放电到 1.49V 直接报废。焊上两颗 100kΩ 分压电阻（BAT+ → 100k → D0 → 100k → GND），固件才能读电量、低电自动休眠；不焊的话屏上电量显示"--"，固件改为连续开机 5 小时自动休眠。
  • 电源键要买"自锁 + 3–6V 灯"款。自复位款松手就断电；12V / 24V 灯的款在 3.7V 锂电下不亮。
  • SD 卡不要超过 32GB。大卡默认是 exFAT，卡槽不认；固件报"SD 卡未就绪"先查格式。
  • 仅充电的 USB 线烧不了固件。批量买线时确认支持数据传输。
  • 换零件型号外壳可能要改。外壳开孔按清单里的尺寸设计：快门孔 Φ11.15、OLED 沉坑 28.6×29、电池仓 42×30×10、电源键 16mm。换成其他尺寸的件，要改 sitas_cam_case.scad 开头的常量重新导出。
