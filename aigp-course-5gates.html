第一关
抽卡新秀10–12 岁
4 参数 · 2 课时
速度档 0.45 m/s		 理论
30min		赛车怎么开才安全
  1. 激光雷达：赛车的眼睛，一秒看十圈；
  2. 三道保命防线：看见→减速→急停（人挡车前现场验证）；
  3. 四个参数是什么：极速 / 前瞻 / 油门 / 刹车点；
  4. 圈速与最速榜：成绩是怎么算出来的。
实操
80min		四参数抽卡调校
  1. 小程序抽卡组车（4 参数 × 3 档 = 81 种组合）；
  2. 先预测“这套卡会更快还是更稳”，跑圈验证；
  3. 换卡对比赛：亲眼看懂每张卡改变了什么；
  4. 成绩实时上大屏最速榜，人人留下圈速记录。
通关
10min		铜牌考核
  1. 抽卡赛计时三圈取最快；
  2. 圈速 ≤ 70 秒 → 颁发铜牌 + 晋级第二关资格。

第二关
调校工程师初中（11–14 岁）
8 参数 · 4 课时
速度档 0.8 m/s		 理论
45min		赛车线与弯道物理
  1. 外-内-外：最快的线为什么不是最短的线；
  2. 转弯半径决定弯中速度上限（本车 0.8m 实测讲解）；
  3. 刹车预瞄与油门斜率：快慢衔接的科学；
  4. 新增 4 参数登场：弯中极速 / 入弯借位 / 转向灵敏 / 跟线松紧。
实操 I
75min		8 参数逐项实验
  1. 单变量法：一次只动一个参数，跑圈记录差异；
  2. 手绘理想赛车线，与车的实际轨迹对比；
  3. 解锁 0.6 m/s 速度档（5 圈零事故自动判定）；
  4. 建立个人参数-圈速实验表。
实操 II
90min		数据复盘调校
  1. 打开黑匣子：逐帧回放位姿 / 偏差 / 速度；
  2. 找出自己最慢的三个路段并定向调参；
  3. 解锁 0.8 m/s 档，冲击 60 秒关口；
  4. 输出个人圈速分析单。
通关
30min		银牌考核
  1. 连续 5 圈零事故 + 计时三圈取最快；
  2. 圈速 ≤ 60 秒 + 当面讲清“我改了什么、为什么快了” → 银牌。

第三关
AI 调校师高中及以上（15 岁+）
须通过前两关
提示词 AI · 4 课时
速度档 1.0 m/s		 理论
45min		怎么跟 AI 工程师说话
  1. 提示词四要素：车况 / 赛道约束 / 目标 / 已知物理；
  2. 好提示与坏提示对比：同一问题两种答案现场演示；
  3. AI 的边界：它哪里比你强、哪里必须质疑；
  4. 安全铁律不可谈判：AI 给的参数也要过车端校验。
实操 I
75min		提示词调参
  1. 向 DeepSeek 描述赛道，索取调校单与预估圈速；
  2. 上车验证：AI 预估 vs 实测，误差归因；
  3. 迭代提示词：补充哪句话让 AI 的方案变好了；
  4. 记录三轮“提示词 → 圈速”演进。
实操 II
90min		人机对决
  1. 我的手调 vs AI 的方案，同车同线对决；
  2. 混合策略：拿 AI 的框架 + 自己的关键改动；
  3. 解锁 1.0 m/s 档，冲击 50 秒关口；
  4. 复盘：这一关你学会的是“驾驭 AI”。
通关
30min		金牌考核
  1. 用 AI 辅助刷新个人纪录，圈速 ≤ 50 秒；
  2. 提交本人最优提示词一份（进入班级提示词库）→ 金牌。
真实教材：DeepSeek 仅凭参数描述推断出“短直道不值得上最高极速、迟滞系统配柔油门”，与车队两小时实测完全一致——第一堂课就重演这场人机对话。

第四关
大模型车队前三关全部通过
自有模型 · 8 课时
正赛规格		 理论
2h		大模型如何当工程师
  1. 系统提示词：给模型一个“车队工程师人格”；
  2. 上下文设计：喂哪些数据（黑匣子 / 赛道图 / 历史圈速）；
  3. 接口标准：OpenAI 兼容接口一把钥匙通所有模型；
  4. 评估方法：怎么证明你的模型比别人的强。
实操 I
3h		打造车队大模型
  1. 接入自选模型（DeepSeek / Kimi / 豆包 / 自部署）；
  2. 编写车队系统提示词 + 数据喂养管线；
  3. 让模型输出整套调校并自动下发车端（安全区内）；
  4. 模型间对决：谁的工程师圈速更快。
实操 II
2h		正赛演练
  1. 排位赛规则：单圈定发车顺位；
  2. 正赛三圈制：撞墙即成绩作废的真规则；
  3. 车队角色分工：车手 / 工程师 / 数据分析师；
  4. 赛前策略会：用自己的模型出作战计划。
结业
1h		正赛 + 数据发布会
  1. 自有模型调校完成正赛三圈 → 结业认证；
  2. 数据发布会：每人用数据讲述自己的赛季；
  3. 成绩与调校档案永久入库，年度积分入账。
真实底气：本页所有速度档与圈速关口，均以自研赛车的真车实测数据锚定——课程不是纸上谈兵，每个数字都跑出来过。

第五关
模型之战四关全部通过
多车大模型对决
赛季制 · 每站半天
联赛积分体系		 理论
1h		多车博弈论
  1. 对手即移动障碍：单车防线如何升级为对抗防线；
  2. 防守线与超车窗口：什么时候让、什么时候抢；
  3. Follow-the-Gap 攻防：缝隙是留给谁的；
  4. 车队策略：圈速快不等于名次好。
实操 I
2h		双车攻防演练
  1. 同场双车跟走练习：保持车距与并线规则；
  2. 攻防回合赛：一攻一守轮换计分；
  3. 各队大模型实时改调校应对对手风格；
  4. 事故裁定实练：碰撞责任判定规则。
实操 II
2h		车队作战室
  1. 三角色分工：车手 / AI 工程师 / 数据分析师；
  2. 赛前：用自家模型生成对手分析与作战计划；
  3. 赛中：工程师席实时调参（安全区内）；
  4. 赛后：数据发布会，模型复盘对决得失。
决战模型之战正赛
  1. 排位 + 正赛：你的大模型 vs 对手的大模型，同场轮对轮；
  2. F1 积分制（25-18-15…），分站积分入年度榜；
  3. 年度前八进总决赛——赛道即擂台，模型即选手。
为什么这是终点：前四关培养的是一个人——会开、会调、会用 AI、会造工程师；第五关检验的是一支车队。这也是唯一没有圈速上限的一关：对手有多强，你就要多快。
