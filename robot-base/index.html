Executive Summary

执行摘要

Crayxus 把同一套「感知—定位—运动」智能底座（"一个大脑"），通过 AI 视觉算法、大模型、机械工程三大能力打造，复用到三条已有样机的产品线。我们以具身智能整机能力落地杭州萧山，补上当地"应用场景"短板，本轮拟引入 ¥1,500 万天使投资，叠加萧山产业政策的非稀释性补贴，实现财务与产业双回报。

03
Core Capability & Moat

三大能力，拧成一套底座

我们的护城河不在单个产品，而在三大能力交汇处沉淀出的通用智能底座——一次研发，跨场景复用。

能力 01 — AI

AI 视觉算法

全局快门相机 + 激光雷达多传感融合，实时感知、定位与建图；端到端神经网络驾驶（DeepRacer 路线），已在赛车与双目高尔夫实测落地。

能力 02 — LLM

大模型能力

云端策略学习（Fleet Learning）与大模型教练 / 自然语言交互，设备越用越聪明并持续 OTA 进化，数据形成正反馈飞轮。

能力 03 — MECH

机械工程

自研整机结构、三电与运动底盘，对接永康精密制造，从图纸到量产全链路打通——把算法装进"能落地的身体"。

一个大脑：技术架构

  • 感知RPLIDAR C1 激光雷达 + 双目 / 全局快门相机
  • 定位Scan-matching 实时建图与厘米级定位
  • 控制统一 v·ω 运动接口，一套指令驱动任意底盘
  • 云端Fleet Learning + OTA，规模越大越聪明
  • 壁垒跨场景复用 → 研发摊薄、数据飞轮、整机+算法一体

07
Landing in Xiaoshan

落地萧山，补上最缺的一环

杭州「强链补链」三年行动方案点名的产业短板，恰好是我们的长板。我们落地萧山具身智能创新中心，可直接对接多项政策红利。

⚠ 萧山 / 杭州的产业缺口

  • 整机制造规模偏小
  • 核心零部件自给不足
  • 中试验证能力薄弱
  • 应用场景开放较少 ← 最痛
  • 创新成果转化率低

✓ 我们一次性补上

  • 具备整机能力 → 候选「头部整机企业」（2027 仅引育 3-4 家）
  • 自研底座 + 永康制造 → 推动零部件本地化
  • 三条线已有样机 → 现成中试与转化案例
  • 一口气带来 3 个可落地应用场景
