02谁能当负责人 · 资格全景(全部列出)

负责人「满足任一条」即过门槛。普通项目门槛(A)较高,青年团队项目(B,负责人及团队平均年龄均 ≤45)逐条放宽。C、D 是不论谁挂帅都要满足的硬性身份与团队要求。

A · 普通项目负责人 满足任一即可

负责人年龄 ≤65 周岁;团队平均年龄 ≤55 周岁。

  • 博士及以上学位
  • 被认定为杭州市 E 类及以上人才(高层次人才分类,E类≈区/市级高级,越往 A 越顶尖)
  • 海外相关工作经历(含创业经历)≥3 年
  • 曾在国内外高校 / 科研院所(新型研发机构)/ 知名企业担任中高级技术职务、管理职务,或科研团队带头人等专业人才

B · 青年团队项目负责人 门槛放宽 · 资助按50%

前置硬条件:负责人 及 团队平均年龄 均 ≤45 周岁。满足后,A 的四条同口径放宽:

  • 硕士学位即可(放宽自博士)
  • 萧山区 F 类人才即可(放宽自杭州 E 类;F类为基础类人才认定)
  • 海外相关工作 / 创业经历 ≥1 年(放宽自 3 年)
  • 在上述机构「有工作经历」即可(放宽自中高级职务)

C · 负责人共同硬性身份 无论谁挂帅都要满足

  • 创始团队核心成员 + 企业主要创始人
  • 第一大自然人股东,或个人持股比例 ≥20%
  • 年龄上限:普通 ≤65 / 青年团队 ≤45

D · 团队 与 依托企业 ≥2名核心成员

  • 团队成员(实际控制人除外)承诺全职在依托企业工作、在萧缴纳社保、聘用期 ≥3 年
  • 依托企业最近 3 年在萧山成立(引进)或拟落地萧山(可先用「拟落地」起步)
  • 产业化型额外门槛:企业获得专业机构投资 ≥1500 万元(湖州国资天使轮可在此发力,见 05)

04七步切入路线

先把不可逆的硬线钉死(主体落萧山、负责人控股),再叠加材料与资本。

  1. ① 锁定「依托企业落萧山」先接触萧山招商 / 区委人才办,明确公司注册落地萧山(或3年内成立)。这是条件3不可让的硬线,也是和湖州国资谈判的前提。
  2. ② 定负责人(化解条件3 vs 条件4矛盾)解法A:你愿控股+全职出任→最干净(IP+控股一肩挑,放下隐身);解法B:李总挂帅(满足控股/全职/台面),教授任首席科学家、你做技术合伙人,IP 装进公司补足条件4;解法C:全员≤45 走青年团队(门槛大降,额度减半)。
  3. ③ 把 IP 确权进公司核心算法专利/软著(8–10项)转让/独占许可给依托企业,坐实条件4「团队拥有自主知识产权」。
  4. ④ 选类别初创型起步拿快速启动资金;湖州国资到位(≥1500万)后冲产业化型 2000万;评估是否选拨投结合。
  5. ⑤ 包装申报材料浙大共研背书 + 全胜大模型实测数据(诚实呈现,不编造已部署数字)+ 机器人底座产业前景 + 永康制造/渠道落地证据链。
  6. ⑥ 双通道报送综合评审为主线,同步报名萧山/杭州创新创业大赛走「以赛代评」。
  7. ⑦ 对齐湖州国资结构按「三问」结果(见05)设计股权与落地结构,确保不把主体注册地/第一大股东/团队社保挪出萧山。
THE BIG QUESTION

05湖州国资天使轮:冲突,还是加分?

结论:通常不冲突,而且是加分——它既能满足产业化型「≥1500万专业机构投资」门槛,又是市场背书。唯一真冲突来自国资可能附带的「注册地 / 返投落地」条款。

为什么是加分 机会面

  • 满足产业化型硬门槛:地方国资平台/政府引导基金一般算「专业机构投资」,若天使轮 ≥1500万且到位,直接够产业化型(2000万)参评线。
  • 强市场背书:即便走初创型综合评审,「已获国资天使轮」是有力的市场验证信号。
  • 利于拨投结合定价:外部投资人给出估值锚,补助转股权时有参照、更顺。

真正的冲突点 风险面

萧山要求依托企业落在萧山、负责人为第一大自然人股东、团队全职在萧缴社保。地方国资(尤其引导基金性质)普遍带「返投/落地」条款:要求被投企业在当地注册,并把募资额的 1–2 倍以投资/产值/税收/就业形式「返投」回湖州。若湖州要求主体注册在湖州,就与「依托企业在萧山」直接撞车。

三种股权/落地结构

方案 A · 主体落萧山,国资纯财务入股推荐

核心运营/研发主体(=依托企业、申报主体)注册萧山;湖州国资在萧山主体层面入股,不要求迁址。前提:湖州能接受「投萧山主体」。最干净,零冲突。

方案 B · 双区结构(总部萧山 + 制造子公司湖州)次优

萧山设总部/研发(申报主体、第一大股东+核心团队社保在此);湖州设制造/中试子公司承接返投义务。永康李总的制造能力本就需要产线,湖州子公司正好放制造,以子公司投资/产值满足返投。需严格守住主体、股东、社保都在萧山。

方案 C · 湖州坚持主体注册湖州慎选/互斥

若湖州不让步,主体在湖州 = 与萧山申报互斥。则需二选一,或推迟湖州投资至萧山落地之后,避免被先入股方绑死迁址。

接洽湖州前,先问清这三件事

问 1 · 是否要求公司主体/法人注册在湖州?(决定走 A/B 还是 C)
问 2 · 返投比例是多少?能否用「湖州制造子公司」的投资/产值来满足?
问 3 · 能否接受「投资萧山主体」这一结构?对回购/对赌/估值条款的底线?
红线(不可踩): 不论怎么接湖州国资,都不能让主体注册地、第一大自然人股东、核心团队社保挪出萧山——否则萧山资格直接不成立。另:国资的回购/对赌/估值会被萧山尽调(尤其拨投结合)看到,天使轮估值别冲太高,提前对齐。顺序上:先定萧山为主体,再敲定湖州条款。
