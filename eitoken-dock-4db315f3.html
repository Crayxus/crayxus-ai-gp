1要解决的问题

  • 笔记本一个 USB 口只给 500mA（2.0）/ 900mA（3.0）。四个 SG90 舵机峰值就要 2.4A，板子直接复位。
  • 树莓派 5 要 5V/5A、Jetson Orin Nano 要 19V、工业步进驱动器要 24V——桌上摆一堆各不相同的适配器。
  • 市售 USB Hub 从电脑那个口取电，再怎么分还是那 500mA。
定义：数据走 Hub 直通电脑，供电完全独立，3.3V 到 24V 一台全包，每一路可测量、可开关、可被 EI TOKEN 读取和控制。

单做电源是红海。差异化不在供电，在于它自己是一台 EI TOKEN 认得出的设备——平台知道每个口挂了什么、吃多少电、哪一路过流。做电源的厂商做不了这件事，因为他们没有平台。

5电气要点

为什么主母线是 24V

要输出 24V 就不能靠升压——大功率 Boost 的效率和纹波都不如 Buck。取 24V 母线 + 各路降压，七路里六路是纯 Buck，只有 CH6 为兼顾 3.3V 下限用 Buck-Boost。

接 PD 时母线只有 20V，24V 档自动锁定，界面灰掉并提示"需接 24V 适配器"。

TPS55288 是 CH6 的关键器件：I2C 直接设定输出电压，不需要外部电位器改 FB。平台下一条指令就能把电压配好。

保护

每路输出前串一颗 eFuse——这是和廉价 Hub 最本质的区别，它们只有一个总保险，一路短路全盘掉电。样机用 TPS2595，量产换 SY6280 / AOZ1360 + 采样电阻。

保护必须双层：eFuse 管微秒级硬件切断（短路），MCU 管毫秒级软件判断（持续过流、缓慢升温）。只靠软件，一次短路就烧板子；只靠硬件，舵机堵转这种"没到限流但一直大电流"看不出来。

热

满载 150W、90% 效率，损耗约 15W，集中在四颗开关电源。铝型材外壳兼散热器，功率区垫导热硅胶片贴壳。NTC ×2 贴主电感与 Buck-Boost 区，70°C 降载、85°C 切断。不上风扇——桌面产品噪音比温度更影响体验。

6「自适应」的边界

层做法是否自动
协议级PD / PPS / BC1.2 握手，对方说要多少给多少全自动，零风险
负载级恒压 + 可编程限流 + 软启动全自动，电源本分
电压级识别设备 → 自动切电压档不自动
红线：CH6 / CH7 绝不自动升压。5V 的板子给 24V，一秒钟就废，而大多数设备不会告诉你它要多少伏。
  • 上电默认永远 5.0V，不记忆上次的高压档
  • 切高压必须：旋钮按下确认，或 EI TOKEN 下发明确指令
  • 高压档该路 LED 常亮黄色，OLED 顶栏显示警示条
  • 调压先断输出再改设定值再上电，绝不带载调压
  • 上电先 5V 软启动再爬升，电流异常立即回落断开
不碰电压能做的聪明事：测插入瞬间的浪涌曲线判断负载类型并自动设限流 · 周期性电流尖峰判定舵机堵转 · 反复触发保护自动降限流并上报 · 总功率超标按优先级降载而非整机掉电 · PD 输入时自动锁掉 24V 档

7固件与平台协议

主控选 ESP32-S3 不是因为最便宜（CH32V203 更便宜），而是因为 EI TOKEN 已经完整支持它：这台底座本身就是平台能一键烧录的设备，固件更新走平台；原生 USB CDC 免驱；VID 0x303A 一插上就被认出。

# 握手
> ID
< EITDOCK v1 sn=D7A7F2C1 ch=7 vin=24.1 src=dc pmax=150

> ST
< 1 usb-a  on  5.02 0.42  2.1 ok
< 5 usb-c  on  5.09 4.62 23.5 pd5v5a   树莓派 5
< 6 term   on 12.01 4.88 58.6 ilim     机械臂到限流
< 7 barrel on 19.02 2.10 39.9 ok      Jetson
< total 133.5W / 150W  temp 61C

# 控制
> ON 3 / OFF 3 / LIM 6 5.0 / SET 6 7.4 / SET 7 19 / CONFIRM / LOG 6

平台侧：案例的 case.json 加一段 "power": { "v": 7.4, "a": 2.5, "ch": "term" }，打开案例即提示「本例需要 7.4V/2.5A，是否切换 CH6？」，点一下自动配置。烧录中电流异常直接提示「CH6 触发限流，检查舵机是否卡死」。

这是护城河。硬件两个月能仿，但「案例知道自己要多少电、平台直接把电源配好」需要平台、案例库、固件三者都在自己手里。

9合规

整机只接 DC，不碰市电。适配器外购已有 CCC 的成品（明纬、台达有 24V/6.5A 现货），本体不属于 CCC 强制目录，省掉 2–3 个月认证和上万元费用。这是把形态定为「DC 输入底座」而非「AC 台式电源」的首要原因。

四条风险与对策
  1. 需求未必刚性——多数入门用户只点个灯。对策：V0 先用现成方案给用户试，看有多少人真的抱怨供电，再决定投不投 V1。
  2. 24V 是双刃剑——覆盖面上去，误操作烧板子的风险也上去。对策：第 6 节那几条红线一条不能省。
