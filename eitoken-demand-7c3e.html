EI TOKEN · 产品与推广

谁一定会用，谁大概率会用

按"不用就干不了活"这一个尺子，把客户和功能分成三层。资源只投前两层，推广只找第一层。

一个判断

能成交的，是那些每天都在为"我们已经解决的问题"花时间的人；不是那些用了更好的人。

看上去很好的产品成交难，是因为客户可以不买。分层的标准只有两条：这个痛是不是每周都在发生，有没有人已经在为它付出成本（工时、退货、差评、课时）。两条都满足是 T0，满足一条是 T1，都不满足是 T2。

客户分层

层客户每天在发生的痛我们消灭的是什么付费方
T0STEM 培训机构、中小学创客课、高校实训室一节课 20 台电脑装环境、驱动、库版本对不上；授课老师不是嵌入式工程师；一个学生编不过，全班停下来等零安装、一键烧录、案例超市。课前不用装机，课中不会卡死。这是每学期都在流的成本机构，按教室 / 学年
T0开发板卖家、板卡厂、套件厂（ESP32 / STM32 板、StackChan 这类）客服每天几十遍"驱动怎么装""烧不进去""为什么不亮"；退货与差评包装上一个二维码：扫码、插上、跑起来。客服问题减半，转化提升厂商，按板型接入 / 联名 / 预装
T1高校学生的课设、毕设有截止日期，环境折腾两天没有进度快速起步。用完即走，付费取决于学校学校（回到 T0）或免费
T12–10 人硬件小团队做原型换一块板重配一次环境；新人上手慢省下环境时间。他们有自己的 IDE，只在起步和换板时用团队订阅，转化中等
T1机器人整机厂的售后与演示（ROS 小车、机械臂）客户收到车不会调，售后远程折腾给客户一个网页：连车、看雷达、推脚本厂商，与上一行合并推进
T1独立创客、爱好者想改代码，不会配环境免费版足够。付费率低，但量大，是口碑和案例的来源少数付费
T2资深嵌入式工程师没有痛，有成熟流程，反感黑盒不推。推了适得其反—
T2工业与企业客户要求离线、审计、认证现阶段满足不了—

功能用同一把尺子

T0没有就不成交

插上能认板、一键烧现成案例、串口看到结果、烧坏能还原、纯网页零安装。已完成，剩真机验证。

T1提高粘性与客单

改代码后云端编译、AI 写代码、Jetson / ROS 板子的终端与面板。已完成，够用即停，不再往深做。

T2好看不买单

成就与排行、采购清单、仿真、能力地图。维持现状，不再投入。

EI HUB（桌面供电枢纽）对机构是 T0——一间教室二十块板的供电和线材是真痛；对个人是 T2。所以它的第一批客户是机构，不做零售定价。

展示套件：每个平台配一件"拿得出手"的东西

客户不看功能清单，看桌上那个东西动起来。选型三条原则：客户已经有的优先（插上就能用最有说服力）、三分钟内能出效果、我们已经在真机上跑通过。每个平台一件主套件，不求全。

mBot（Makeblock 一代，mCore 主板）AVR · Arduino约 ¥450
为什么是它
国内中小学创客教室保有量最大的 Arduino 小车，很多学校仓库里有一箱在吃灰——"你们现有的 mBot 插上就能用"比任何演示都有力。主板就是 ATmega328P + CH340，平台已能认、能烧。
三分钟演示
插上 → 认出 Arduino Uno → 一键烧「超声波避障」→ 放地上自己绕开椅子腿 → 让 AI 改成"离墙 10cm 就倒退并响一声"→ 云端编译 → 再烧。
现状
要补 5 个 mBot 专用案例（巡线、避障、遥控、灯光、蜂鸣），用 Makeblock 库，约一天；认板烧录已有。备选：通用「Arduino Uno 37 合 1 传感器套件」（约 ¥120），现有 51 个案例大部分直接能用，给没有 mBot 的机构。
M5 StackChan（CoreS3）ESP32-S3约 ¥900
为什么是它
有脸、会转头、会说话——现场最吸引人的一件；社区热度高，家长和校长一眼就懂。
三分钟演示
插上 → 认出 StackChan → 一键烧「点头」「表情」→ 烧「离线语音」，现场用中文喊它转头。
现状
就绪 9 个专用案例全部真编译通过，离线语音模型已处理。
Black Pill 遥控云台STM32约 ¥80
为什么是它
STM32 的卖点是"工业级芯片，但像 Arduino 一样简单"。Black Pill + 两个舵机云台 + 摇杆 + OLED，便宜、好带，正好展示"插 USB 就烧"——这件事别人家做不到。
三分钟演示
首次：按住 BOOT0 插上 → 一键初始化 → 之后插上就烧「摇杆控制」→ 推摇杆云台跟着转，OLED 显示角度。
现状
要补 1 个组合案例（摇杆 + 双舵机 + OLED，由现有三个案例拼成）；初始化和烧录代码已完成，待真机验证。大场合可加展 ZYArm-X1 六轴机械臂（STM32，已在经典版跑通），做视觉冲击。
幻尔 ROS 小车（Jetson，JetAuto / ROSOrin 系）ROS · Jetson约 ¥5,000–8,000
为什么是它
高校和高中竞赛班最常见的 ROS 平台；我们的 ROS 面板就是按幻尔的话题命名做的，ROSOrin 双车实战时整条链路跑通过。
三分钟演示
USB 连 Jetson → 登录 → 自动认出型号和 ROS → 雷达图实时刷新 → 方向盘开车 → 推一段避障脚本，车自己走。
现状
就绪 1.0 的终端、ROS 面板、实时状态已完成，待真机验证。只对高校和竞赛机构带，不作为通用展示。
地瓜 RDK X5 + USB 摄像头RDK约 ¥700
为什么是它
国产 AI 板，BPU 算力；和地瓜的合作口径一致（COS 演示本来就定在 RDK X5）。
三分钟演示
连上 → 实时状态里看到 BPU 占用 → 推一段人脸 / 物体识别脚本，终端里实时打印识别结果。
现状
要补 1 个视觉演示脚本；终端与状态已完成。
NXP FRDM（任选一块）自定义约 ¥150
为什么是它
专门用来回答"我们的板子你们认不认"——认得出调试器、打得开串口、AI 能帮写驱动。给板卡厂商看，证明不挑板。
现状
就绪 识别和串口已上线；烧录不支持，现场如实说明。

推广终点

两类客户：培训机构按教室卖席位，板卡厂商按板型联名。个人用户免费，作为口碑与案例来源，不作为收入来源。

  1. 先测通，再上门。按交付测试清单在全新电脑上把 P0 全部跑过，带着结果去见客户。
  2. 各找 3 家试点。3 家机构（一间教室、一个学期）+ 3 家板卡店（一个板型、包装二维码）。目标不是收入，是拿到"上课不用装机""客服问题少了多少"这两个数字。
  3. 用数字定价。机构按教室 / 学年，厂商按板型 / 年；价格从试点数据倒推，不拍脑袋。
  4. 只讲一句话。对机构："学生插上就能跑，老师不用会嵌入式。"对厂商："买家扫码插上就亮，客服少一半。"
