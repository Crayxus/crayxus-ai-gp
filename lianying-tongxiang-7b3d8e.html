桐乡社区茶点店 · 联营合作框架

轻资产联营 · 以门店分润为核心 · 投资方优先回本
投资方（甲方）：我方（提供桐乡场地 + 投资装修）　·　运营方（乙方）：佬泰丰斋品牌方 / 嘉兴南泰餐饮（提供品牌授权 + 全套运营）

本框架核心立场

  • 不合资、不换股——单店试水，用《联营合作协议》而非股权绑定，可进可退、止损灵活。
  • 定位为社区日常茶点店，品牌光环有限，因此品牌授权费压到象征性，价值落在真实生意与分润上。
  • 重资产是甲方的（场地 + 装修），故分润与保护条款向甲方倾斜：优先回本、实时查账、同业禁止、装修归属、短约可退。
  • 核心只看两件事：有没有生意、分润怎么分。其余从简。

一、合作定位与核心逻辑

甲方在桐乡（地址待填）已有一处约 __㎡ 商铺（市价年租金约 ¥3.5 万），拟开设一家以社区日常茶点 + 区域伴手礼为主的门店。甲方负责提供场地并投资装修，乙方以"佬泰丰斋"品牌授权 + 全套运营方式进驻经营，双方按门店实际经营利润分润。本合作不成立新公司、不涉及股权，仅就该单一门店进行联营。

三、门店损益核算与分润机制 核心

1. 门店经营利润如何算

每月按门店实际经营核算：

门店经营利润 = 营业收入 −（原料 + 人工 + 水电杂费 + 平台佣金 + 包材 + 门店营销 + 场地租金）

说明：场地租金 ¥3.5 万/年计入门店成本，由门店收入承担、双方通过分润共担；装修为甲方一次性资本投入，不计入此处，单独优先回收（见下）。

2. 两段式分润（保护重资产方）

阶段分润规则（建议值，可议）
回本期
（甲方装修投入未收回前）		 门店经营利润：甲方 70% / 乙方 30%。甲方部分用于回收装修款；乙方 30% 为运营基础报酬，保障运营团队积极性。直至甲方累计回收装修款 100%（建议设 24 个月 内优先回收的封顶约定）。
回本后
（装修收回后长期合作）		 门店经营利润：甲方 55% / 乙方 45%。甲方因持续提供场地资产与已投装修占多；乙方因品牌 + 运营取其份。

备选：若约定场地租金由甲方单独承担（不计入门店成本），则回本后分成相应上调至 甲方 60% / 乙方 40%。二者择一，签约前确定。

3. 品牌授权费

鉴于本店定位为社区日常茶点、品牌溢价有限，品牌授权费仅作象征性收取或并入乙方分润、不再单独抽取（建议每年 ¥__ 千，或直接含于上述乙方分成内）。避免品牌方"躺着抽成"侵蚀门店利润。

四、投资方保护条款（重资产方） 关键

甲方不参与日常运营，但承担最重投入，故须有以下硬保障：

  • 优先回本：回本期内门店经营利润优先用于甲方回收装修，乙方仅取基础运营报酬。
  • 实时查账（最重要）：收银系统 / 小程序 / POS 后台向甲方实时开放只读权限；门店收款账户由双方共管或对甲方可见；每月对账、甲方可随时查账、每年可自费请第三方审计。乙方瞒报、截留流水的，按瞒报额 3 倍赔偿并可即时终止合作。
  • 同业禁止：合作期内及终止后一年内，乙方不得在桐乡市区另设同品牌或同类竞品门店，避免分流本店客源。
  • 装修与资产归属：装修及固定设备所有权归甲方；合作终止后留归甲方，甲方有权自营或更换品牌继续经营该址。
  • 短约可退：首期合作 3 年；甲方在年度经营评估严重不达标时有权提前终止。
  • 运营标准：乙方未达约定的卫生、出品、服务标准且整改不力的，甲方可要求更换运营负责人直至终止。

五、品牌价值与"可换牌"说明 回应核心疑问

为什么把品牌放在次要位置？本店主打社区日常茶点、本地客与复购，老字号/非遗背书在礼盒、文旅伴手礼赛道才显著值钱，在社区日常消费场景作用有限。因此本框架不为"用品牌"支付高溢价，而是：

  • 品牌授权费象征化、授权范围仅限本店、所有权仍归乙方；
  • 甲方掌握场地 + 装修 + 查账权，并保留合作终止后换牌自营的灵活性——即便不用佬泰丰斋，门店硬件与位置仍是甲方资产；
  • 真正绑住合作的是生意与分润，而非招牌。生意好则共赢续约，生意一般则甲方可低成本止损或换牌。

六、退出与终止

  • 到期：首期 3 年期满，双方可协商续约。
  • 提前退出：任一方提前 3 个月书面通知；乙方撤场带走品牌招牌、物料、配方与会员数据，甲方留下装修与场地。
  • 即时终止（乙方严重违约）：瞒报截留流水、重大食品安全/卫生事故、擅自闭店或转让运营权的，甲方可即时终止并索赔。
  • 库存与结算：终止时按成本价结算在库原料与成品，30 日内完成清算。
